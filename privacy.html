隱私說明（v3）

這是個人實驗性網站。Spotify 與聊天是兩套獨立功能。Spotify 使用 OAuth PKCE 讀取並顯示目前播放與最近 20 筆播放紀錄；網站在前景時每約 30 秒更新目前播放，回到前景時再次查詢。最近播放資料只在頁面記憶體中顯示；不另外永久儲存或上傳到 Cloudflare、D1 或 OpenAI，不產生聆聽者分析，也不把 Spotify API 資料交給 AI。新增近期播放功能需要重新授權 user-read-recently-played 權限。

如果你選擇啟用雲端聊天，自己輸入的聊天內容會經由你設定的 Cloudflare Worker 傳送至 OpenAI API 生成回覆；聊天雙方的文字儲存在 Cloudflare D1 資料庫。你主動釘選的記憶也儲存在 D1，直到你刪除。這些雲端對話可能包含私人資訊，請不要輸入高敏感資料。

Worker 的 OpenAI API 金鑰只應儲存在 Cloudflare Secret；聊天通行碼預設僅在本次網頁開啟時保留；若你主動勾選「記住這台裝置」，成功連線後會將聊天通行碼以未加密形式儲存於本機 localStorage，以便日後自動連線。其他能存取本裝置或這個網站儲存空間的程式，可能讀取該通行碼。關閉此選項或按「本機登出」會清除本機保存的通行碼；若裝置遺失或通行碼外洩，應在 Cloudflare 更換 LING_ACCESS_CODE。網站也會保存 Worker 網址。Spotify Client ID 存放在本機瀏覽器 localStorage；Spotify 更新令牌依你的選擇存於 sessionStorage 或 localStorage。關閉瀏覽器或切到其他 App 時，iOS 可能暫停網頁，因此本網站不承諾背景持續更新。請不要在共用裝置使用保留登入功能。

聊天室的「清空雲端對話」會刪除 D1 中所有一般對話，不會清除釘選記憶。每則長期記憶可個別刪除；備份按鈕會分頁匯出目前共用資料庫保存的完整對話與釘選記憶。若要完整匯出或刪除資料，可在 Cloudflare D1 控制台操作。

為處理 API 請求，Cloudflare、OpenAI 和 GitHub 可能依其各自政策處理必要的技術資料。此 ChatGPT 對話與本獨立服務沒有自動同步。Spotify 開發者政策 · OpenAI 隱私政策
