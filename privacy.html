隱私說明（v3）

這是個人實驗性網站。Spotify 與聊天是兩套獨立功能。Spotify 使用 OAuth PKCE 讀取並顯示當下播放及最近播放（最多 20 筆）；最近播放只在目前頁面顯示，不另外永久儲存播放歷史、不產生聆聽者分析，也不把 Spotify API 資料交給 AI。

如果你選擇啟用雲端聊天，自己輸入的聊天內容會經由你設定的 Cloudflare Worker 傳送至 OpenAI API 生成回覆；聊天雙方的文字儲存在 Cloudflare D1 資料庫。你主動釘選的記憶也儲存在 D1，直到你刪除。這些雲端對話可能包含私人資訊，請不要輸入高敏感資料。

Worker 的 OpenAI API 金鑰只應儲存在 Cloudflare Secret；聊天通行碼預設僅在本次網頁開啟時保留；若你主動勾選「記住這台裝置」，成功連線後會將聊天通行碼以未加密形式儲存於本機 localStorage，以便日後自動連線。其他能存取本裝置或這個網站儲存空間的程式，可能讀取該通行碼。關閉此選項或按「本機登出」會清除本機保存的通行碼；若裝置遺失或通行碼外洩，應在 Cloudflare 更換 LING_ACCESS_CODE。網站也會保存 Worker 網址。Spotify Client ID 存放在本機瀏覽器 localStorage；Spotify 更新令牌依你的選擇存於 sessionStorage 或 localStorage。請不要在共用裝置使用保留登入功能。

若你另行啟用 v4 背景 Spotify 查詢，網站會在你勾選明確同意後，將 Spotify 更新令牌經 HTTPS 傳到 Cloudflare Worker，並以 AES-GCM 加密保存於 D1。系統每約 10 分鐘查詢一次目前播放狀態；D1 只保留當前歌曲的單向雜湊與通知節流時間，不保存歌曲歷史、歌名、演出者或播放統計。這些資料不會送給 AI 或推播服務。歌曲改變時，推播僅包含不指名歌曲的提示。停用背景查詢會刪除 Spotify 授權憑證及目前比對值。Spotify 開發者 refresh token 期限目前為六個月。請參閱 Spotify Developer Policy。

若你另行允許通知，系統會將該裝置的 Web Push 訂閱端點與公鑰存入 D1，並經瀏覽器推播服務發送通知。每日主動問候採固定文字（非即時 AI 生成），並寫入雲端對話記錄；可在背景設定關閉。取消通知訂閱可刪除該裝置的端點，清除 D1 時亦可刪除所有訂閱。Cloudflare Worker 加密密鑰衍生自原有的高強度 LING_ACCESS_CODE，更換通行碼後，必須重新設定背景授權或推播密鑰。

聊天室的「清空雲端對話」會刪除 D1 中所有一般對話，不會清除釘選記憶。每則長期記憶可個別刪除；備份按鈕會分頁匯出目前共用資料庫保存的完整對話與釘選記憶。若要完整匯出或刪除資料，可在 Cloudflare D1 控制台操作。

為處理 API 請求，Cloudflare、OpenAI 和 GitHub 可能依其各自政策處理必要的技術資料。此 ChatGPT 對話與本獨立服務沒有自動同步。Spotify 開發者政策 · OpenAI 隱私政策
