隱私說明

本工具是非官方、單一頁面的 Spotify 播放資訊顯示工具。它不設立自家伺服器、不設資料庫、不追蹤使用者，也不傳送歌曲資訊給 OpenAI 或任何 AI 模型。

妳提供的 Spotify Client ID 存在這個網站來源的瀏覽器 localStorage 中。Spotify OAuth 授權使用 PKCE，並請求 user-read-currently-playing 權限。存取令牌在當前頁面記憶體中使用。更新授權令牌（refresh token）預設保留於瀏覽器 sessionStorage；若主動勾選「在本機保留登入授權」，才改為 localStorage。登出按鈕將清除本機令牌與 Client ID；如需撤銷 Spotify 授權，請至 Spotify 帳戶設定的 Apps 頁面操作。

本工具直接向 Spotify API 請求並顯示目前播放的歌曲資訊。播放資料不會保留成長期紀錄，亦不建立收聽者偏好檔案。歌曲名稱、封面等由 Spotify 提供，使用受到 Spotify 隱私權政策和開發者條款規範。

若把網站部署於 GitHub Pages，GitHub 可能依其隱私權政策處理網站存取相關紀錄；本工具沒有控制其平台層級紀錄。妳可以自行部署於信任的靜態網站平台。

參考：Spotify 隱私權政策、GitHub 隱私聲明。
